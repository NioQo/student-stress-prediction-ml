# Student Stress Level Prediction using Machine Learning

## Project Overview
Machine learning classification model to predict stress levels (low, medium, high) in university students using psychological, academic, social, and physiological features.

## Dataset
- 1,100 students
- 21 features
- Source: Public Kaggle dataset

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest

## Evaluation Metrics
- Accuracy
- ROC AUC

## Results
- Best model: Random Forest
- ROC AUC: 98.4%

## Key Features
- Blood pressure
- Academic performance
- Study load
- Social support
- Teacher-student relationship

## Tools & Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
